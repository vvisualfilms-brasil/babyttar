# Babyttar

App pessoal (PWA) para registrar a rotina do bebê: sono, mamadas, fraldas, tummy time, banho, remédios e crescimento, com sincronização entre os dois responsáveis.

- Hospedagem: GitHub Pages (grátis). Os dados ficam num repositório **privado** separado (`babyttar-dados`), gravados pela API do GitHub.
- Funciona offline; sincroniza a cada ~30 s.
- Não faz diagnósticos nem substitui orientação pediátrica.

Documentação:
- [Arquitetura e planejamento](docs/01-Arquitetura-e-Planejamento.md)
- [Como publicar e instalar](docs/02-Como-publicar-e-instalar.md)

Desenvolvimento: `npm install`, `npm run dev`, `npm test`.
